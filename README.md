## ⚡ Quick Start (Running Locally)

To explore this portfolio on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/tesha-collab/Pantaleo-portifolio.git
   cd portifolio
   ```

2. **Open the project:**
   * Double-click `index.html` in your file explorer to open it directly in any modern browser, or
   * Use VS Code with the **Live Server** extension: right-click `index.html` and choose **"Open with Live Server"**.
